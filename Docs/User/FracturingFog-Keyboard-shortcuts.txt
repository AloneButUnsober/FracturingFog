Fracturing Fog Keyboard Shortcuts
=================================
v0.6.x — Avalonia shell

For a Markdown version with mouse + sub-dialog hotkeys see
Keyboard-Shortcuts.md.

GLOBAL (any fractal, any mode)
------------------------------
M       Open the Control Center (the main menu). The old Floating
        Menu window was retired; the toolbar Menu button, M, and a
        right-click on the render surface all open it now.
T       Toggle Color Theme Editor
R       Reset view to default for active fractal
V       Save current view as a region
Backspace  Back — return to the previous view in nav history
Esc     Exit Span mode / stop slideshow / stop video zoom /
        close active sub-dialog

OVERLAYS & EXPORT PREVIEW
-------------------------
G       Toggle coordinate grid overlay
K       Toggle watermark overlay
H       Toggle performance HUD   (Shift+H resets its averages)
X       Toggle Post-FX HUD overlay
Ctrl+H  Toggle Post-FX HUD overlay (second binding for X)
P       Open Fractal Parameters dialog
F1      Open Help window
Ctrl+Shift+P  1:1 poster / wallpaper preview window
Ctrl+Shift+F  Toggle export-aspect frame guide overlay

UI SCALE (accessibility) — works from any window incl. the render window
------------------------------------------------------------------------
Ctrl++  Increase global UI scale one step (Ctrl+= / keypad + also)
Ctrl+-  Decrease global UI scale one step
Ctrl+0  Reset UI scale to 100%
        (the fractal surface is not scaled, only the UI chrome)

DEEP-ZOOM DIAGNOSTICS (title shows a suffix while engaged)
----------------------------------------------------------
Ctrl+G        Toggle GPU compute (single-precision Mandelbrot)
Ctrl+Shift+A  Toggle Mandelbrot acceleration (perturbation/BLA)
Ctrl+Shift+S  Toggle Series Approximation
Ctrl+Shift+D  Toggle double-double (DD) BLA precision
Ctrl+Shift+G  Toggle GPU relief-raymarch (off = CPU parity oracle)

2-D NAVIGATION (Mandelbrot, Julia, Burning Ship, ...)
-----------------------------------------------------
W       Zoom in (centred)
S       Zoom out (centred)
A       Pan left
D       Pan right
Q       Pan up
E       Pan down
Shift   Hold with any pan key for a quarter-step nudge
Shift+W Zoom in, quarter-step (fine)
Shift+S Zoom out, quarter-step (fine)

3-D NAVIGATION (Mandelbulb, User Bulb 3D)
-----------------------------------------
W       Camera closer (distance -)
S       Camera farther (distance +)
Shift+W Camera closer, quarter-step (fine)
Shift+S Camera farther, quarter-step (fine)
A D Q E Pan in screen space
Arrow Up    Tilt camera up (phi +)
Arrow Down  Tilt camera down (phi -)
Arrow Left  Orbit theta -
Arrow Right Orbit theta +
PgUp    Light azimuth -
PgDn    Light azimuth +
Home    Light elevation -
End     Light elevation +

MOUSE — 2-D
-----------
Wheel up/down       Zoom in/out at cursor
Left-click drag     Pan (fast pass mid-drag; 300 ms debounced full
                    re-render after release)
Double-click        Center on point + zoom in one step
Right-click drag    Highlight-to-zoom — marquee box; release centers
                    + zooms to fill rectangle (v0.6 feature)
Alt+double-click    Relief DOF focus pick (Relief 3D raymarch with
                    perspective + depth of field only; recenter else)

MOUSE — 3-D
-----------
Wheel up/down       Camera closer/farther
Left-click drag     Pan in screen space
Right-click drag X  Orbit theta (azimuth)
Right-click drag Y  Orbit phi (elevation, inverted for natural feel)
Middle-click drag   Marquee zoom (3-D equivalent of the 2-D right-drag
                    box; right-drag stays camera-orbit in 3-D)

FOCUS BEHAVIOR
--------------
Keyboard pan/zoom/camera keys are IGNORED while any text box has
keyboard focus (CX, CY, Zoom, Iter, equation editor, ...). Click
the render surface to restore focus. v0.6.2 fixed a regression
where toolbar clicks permanently stole focus.

SLIDESHOW VCR (mouse only — visible while slideshow runs)
---------------------------------------------------------
<<      Previous region
<       Previous theme within region
||      Pause / Resume
>       Next theme within region
>>      Next region

MODIFIER COMBINATIONS
---------------------
Shift + click Slideshow   Lock current region (only themes cycle)
Shift + pan key            Quarter-step nudge

SUB-DIALOG HOTKEYS
------------------
Ctrl+S        Save (Color Theme Editor, equation editors)
Ctrl+Shift+S  Save As (equation editors)
F5            Force recompile (equation editors)
Esc           Close any sub-dialog
Enter         Apply / Go (CX/CY/Zoom/Iter fields in the Control
              Center's Explore section)
