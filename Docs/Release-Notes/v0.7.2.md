# Fracturing Fog 0.7.2 — what's new since 0.7.1

Summary for release announcements and forum posts. It covers the 248 pull requests merged
between `v0.7.1` and the 0.7.2 release commit (PRs #1475–#2010). Issue numbers are on
<https://github.com/AloneButUnsober/FracturingFog/issues>.

**Sources.** Every item lists its main sources. All of them are credited in full in the
project bibliography,
[`Docs/Resources-Bibliography.md`](https://github.com/AloneButUnsober/FracturingFog/blob/main/Docs/Resources-Bibliography.md),
with what FF takes from each and what is not yet verified. The links below jump to the
entry. Where FF found prior art, the bibliography says so, and FF claims no novelty beyond
what it states there.

## Highlights

- **Zoom past 10¹⁰⁰.** The 1e100 ceiling is gone. A new *Unbounded* quality tier uses an
  arbitrary-precision reference orbit and float-exp pixels, on the CPU, the GPU and the
  render cluster.
- **Deep zoom in every 2D family.** A generic perturbation engine takes Julia, Multibrot,
  Tricorn, Burning Ship, Magnet, Phoenix, Spider, Glynn, Nova, TearDrop, CalcGen formulas
  and User Equations past double precision.
- **Faster deep zoom.** Period-synchronised linear approximation (LA) is on by default
  from 1e30, with periodicity early-outs and a measured per-device choice of deep-zoom route.
- **New physics families.** Black hole shadows, gravitational and Hamiltonian scattering
  basins, microlensing maps, Wada mirror spheres, chaotic-billiard ray densities and
  double-slit interference fractals.
- **Math Plane.** A 2D and 3D maths canvas with curves, maps, phase portraits and scripted
  animated scenes. It can also draw a maths overlay on live fractal views.
- **Snappier live view.** The first frame arrives in about 2 s instead of 23 s, and drags
  and window resizes no longer stall or tear.

## New features

### Arbitrary-precision deep zoom past 10¹⁰⁰ (epic #1428)

- **BigFloat and an exact view centre** (#1830, #1832, #1833). The view centre is stored
  exactly, in the view state, region JSON, history, video, server and cluster.

- **Arbitrary-precision reference orbit on the CPU** (#1840), with orbit arrays that grow
  as they are built (#1856).

  exponent range (#1842, #1845, #1847, #1886, #1889).

  auto-explore and Misiurewicz loop video (#1866, #1868, #1870, #1873, #1876, #1878).

### Faster deep zoom

- **Period-synchronised LA** (epic #1623). LA stages are built with the reference orbit,
  and the approximation transform and a 4-lane AVX2 evaluator are added. LA is on by
  default from 1e30 (#1624–#1629). It also runs as a GPU kernel and on the float-exp kernel
  (#1630, #1664), and climbs back at shared stage boundaries (#1614).
- **Reference orbit stops at its period** for nucleus-centred views (#1614). QD-band pixels
  resume rebasing with BLA (#1613).
- **Periodicity early-outs** in the deep orbit paths, the PT4 / PT8 rows, the rebased
  loops, the LA evaluator and the GPU deep kernels (#1368, #1800, #1802–#1805).
- **Per-device deep-route calibration** (#1665). FF times the CPU and GPU deep routes once
  per device and uses the faster one. There's a GPU deep zoom toggle, a route panel and a
  HUD line, plus `--gpu-deep` and `--deep-route-calibration` in batch (#1785–#1788, #1493).
- **Cancellable reference orbit**, reused by the AA samples (#1427). Deep ray landing is
  2.8–3× faster on long preperiods (#1872).
- *Sources:* [Imagina](https://github.com/AloneButUnsober/FracturingFog/blob/main/Docs/Resources-Bibliography.md#imagina)
  (5E-324 / Zhuoran, `HInfLAEvaluator`; FF's LA code is derived from it and listed in
  `THIRD-PARTY-NOTICES.md`), Munafo's Mu-Ency *Bivariate Linear Approximation*,
  [Fractalshades math notes](https://github.com/AloneButUnsober/FracturingFog/blob/main/Docs/Resources-Bibliography.md#fractalshades-math)
  (gbillotey), the [fractadyne bench-kit](https://github.com/AloneButUnsober/FracturingFog/blob/main/Docs/Resources-Bibliography.md#fractadyne-bench-kit)
  (WindySnowOwl) used to measure, and rith's
  [0.7.1 benchmark](https://github.com/AloneButUnsober/FracturingFog/blob/main/Docs/Resources-Bibliography.md#rith-benchmark-thread),
  whose findings started #1611–#1615.

### Math Plane (epics #1547, #1557, #1556, #1730)

- **Math Plane 2D** (#1548–#1555). Axes, points and vectors; explicit, parametric, polar
  and implicit curves; shaded regions; matrix maps animated in *t* with det and
  eigenvectors; complex maps with an f′(z) probe and phase portrait; orbit and cobweb
  diagrams over a fractal backdrop. Scenes can be saved, recalled, imported and exported
  (#1637, #1694).
- **Scripted scenes** (#1695–#1701). Timed `step` / `with` statements, reveal actions,
  camera moves, a Control Center player, headless script video, and Scene Engine shots
  that play a script.
- **Math Plane 3D** (#1713–#1719). Surfaces, space curves, 3×3 maps, implicit surfaces
  F(x, y, z) = 0, and glTF / GLB / STL mesh export.
- **Fractal bridge** (#1731–#1736, #1741). A 3D fractal meshed into the scene, an orbit
  under a fractal's own step, exact raymarcher cameras, and a maths overlay on live 3D

  pins a point, #1748). The overlay is also drawn on every video frame (#1746).

  a scattering pixel's path to the Math Plane, in 2D and 3D (#1993, #2000, #1996).
